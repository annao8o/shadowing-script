# Shadowing Script (쉐도잉 스크립트) — 설정 안내

외국어 대본을 멘트별로 듣고 따라 말하는 연습 사이트입니다. 세트마다 연습 언어를 정할 수 있어서, 인도네시아어 말고 다른 언어로 바뀌어도 그대로 쓸 수 있어요.
**전체 공개 세트는 로그인 없이 누구나** 보고 연습할 수 있어요. 대본을 추가하거나 내 세트를 고치거나 공유 알림을 받을 때만 이 사이트 전용 **아이디·비밀번호**로 로그인합니다 (Claude 계정은 필요 없어요).
필요한 것: **Supabase 계정**(데이터 저장, 무료), **GitHub 계정**(사이트 호스팅, 무료). 처음 한 번 20분 정도 걸립니다.

파일 3개
- `index.html` — 사이트 자체
- `setup.sql` — 데이터베이스 설정 (한 번만 실행)
- `README.md` — 이 안내

---

## 1. Supabase 프로젝트 만들기

1. https://supabase.com 에서 가입하고 **New project**를 누릅니다.
2. 이름은 자유(예: `shadowing`), Region은 **Northeast Asia (Seoul)**, 데이터베이스 비밀번호는 아무거나 길게 정해 둡니다.
3. 프로젝트가 만들어질 때까지 1~2분 기다립니다.

## 2. 데이터베이스 설정 (setup.sql)

1. `setup.sql`을 메모장 등으로 엽니다.
2. **맨 아래 두 곳을 바꿉니다.**
   - `'여기에-관리자-키를-적으세요'` → 본인만 아는 긴 비밀번호 (모든 세트를 고치고 지우고, 비밀번호를 잊은 사람의 비밀번호를 새로 정해 줄 수 있는 키)
   - `'여기에-참여코드'` → **회원가입할 때** 필요한 코드. 함께 쓸 사람들에게만 알려 주세요 (예: `'latihan2026'`)
     아무나 가입해도 된다면 따옴표까지 지우고 `null`로 바꿉니다.
3. Supabase 왼쪽 메뉴 **SQL Editor** → 새 쿼리에 파일 전체를 붙여 넣고 **Run**.
   `Success. No rows returned`가 나오면 성공입니다.

> 이전 버전의 setup.sql을 이미 실행했다면 이 파일을 그대로 한 번 더 실행하면 됩니다. 기존 세트는 ‘전체 공개 · 인도네시아어’로 유지됩니다. 올린 데이터는 유지되고, 이전 버전에서 세트를 올렸던 기기로 가입·로그인하면 그 세트가 자동으로 내 계정으로 옮겨집니다.
>
> 관리자 키나 참여 코드를 나중에 바꾸고 싶으면 맨 아래 `insert into public.settings ...` 부분만 고쳐서 다시 Run 하면 됩니다. 데이터는 지워지지 않습니다.

## 3. 사이트에 Supabase 연결

1. Supabase 왼쪽 아래 **Project Settings** → **API** (또는 **API Keys**) 화면을 엽니다.
2. 두 값을 복사합니다.
   - **Project URL** (예: `https://abcdxyz.supabase.co`)
   - **anon public** 키 또는 **publishable** 키 (`eyJ...` 또는 `sb_publishable_...`)
   - ⚠️ `service_role` 키나 `secret` 키는 **절대** 넣지 마세요. 사이트 파일은 누구나 볼 수 있습니다.
3. `index.html`을 메모장으로 열고 `NASKAH_CONFIG` 부분의 두 값을 바꿔 저장합니다.

```js
window.NASKAH_CONFIG = {
  url: 'https://abcdxyz.supabase.co',
  key: 'eyJhbGciOi...'
};
```

## 4. GitHub Pages로 사이트 공개

1. https://github.com 에서 가입 후 오른쪽 위 **+** → **New repository**.
   이름 예: `shadowing`, **Public** 선택 → **Create repository**.
2. **uploading an existing file** 링크(또는 **Add file → Upload files**)를 눌러 `index.html`을 올리고 **Commit changes**.
3. 저장소의 **Settings → Pages** → Branch를 `main`, 폴더 `/ (root)`로 두고 **Save**.
4. 1~2분 뒤 같은 화면 위쪽에 주소가 나옵니다: `https://내아이디.github.io/shadowing/`
   이 주소를 연습할 사람들에게 보내면 됩니다.

> `index.html`을 고친 뒤에는 2번처럼 다시 올리면(같은 이름으로 덮어쓰기) 1~2분 뒤 반영됩니다.

## 5. 처음 열었을 때

1. 사이트를 열면 바로 세트 목록이 보여요. **로그인** 버튼 → **처음이에요 · 회원가입**에서 이름·아이디·비밀번호·참여 코드를 넣고 가입합니다.
2. 목록 화면의 **내 정보** 버튼에서 **관리자 키**(2단계에서 정한 키)를 넣고 **관리자 모드**를 누릅니다. (본인 기기에서만)
3. 연습만 할 사람에게는 **사이트 주소**만, 대본도 올릴 사람에게는 **사이트 주소 + 참여 코드**를 알려 주세요.

## 6. 세트 만들기: 언어와 공유 범위

새 대본을 추가할 때 두 가지를 고릅니다.

**연습할 언어** — 목록에 언어가 표시되고, 위쪽 언어 버튼으로 걸러 볼 수 있어요. 기계 음성도 그 언어 목소리로 읽어요.
- 한글 발음 자동 생성은 **인도네시아어·말레이어**만 돼요. 다른 언어는 대본에 `대사 | 한글 발음 | 한국어 뜻`처럼 직접 적은 발음만 보여요.

**공유 범위**
- **전체 공개**: 로그인한 모든 사람의 목록에 보여요.
- **일부 공개**: `@아이디`나 이름으로 사람을 찾아 지정해요. 지정받은 사람 화면에 알림이 뜨고, **수락**을 누르면 그 사람 목록에 들어가요. 거절하면 들어가지 않아요.
- **비공개**: 나만 봐요.
- 만든 뒤에도 세트 화면 아래 **공유 설정**에서 범위와 사람을 바꿀 수 있고, 누가 수락했는지도 보여요.
- 공유받은 사람은 세트 화면 아래 **내 목록에서 빼기**로 언제든 뺄 수 있어요.
- 알림은 사이트를 열 때, 다시 화면으로 돌아올 때, 열어 둔 동안 30초마다 확인해요. 브라우저 탭 제목에도 `(1)`처럼 알림 수가 표시돼요.

## 7. claude.ai 페이지의 데이터 옮기기

1. claude.ai의 기존 연습 페이지에서 **백업** → **녹음 파일도 포함** 체크 → **백업 파일 내려받기**.
2. 새 사이트에서 **백업** → **백업 불러오기** → 그 파일 선택.
   녹음까지 그대로 옮겨집니다. (녹음 없이 백업한 세트는 기계 음성 세트로 들어옵니다.)
   백업에서 불러온 세트는 전체 공개로 들어오고, 일부 공개였던 세트는 공유 대상이 백업에 없어서 비공개로 들어옵니다.

## 알아 둘 점

**로그인 없이 할 수 있는 것 / 로그인해야 하는 것**
- 로그인 없이: 전체 공개 세트 보기, 듣기, 따라 말하기 연습, 백업 내려받기
- 로그인 필요: 대본 추가, 내 세트 고치기·지우기·공유 설정, 일부 공개 세트 받기(알림), 비공개 세트 보기
- 로그인하지 않은 사람에게는 일부 공개·비공개 세트와 휴지통이 전혀 보이지 않아요.

**로그인**
- 한 번 로그인하면 그 기기에서는 계속 로그인된 상태로 유지됩니다 (180일 동안 안 쓰면 다시 로그인).
- 다른 기기에서도 같은 아이디·비밀번호로 로그인하면 내 세트를 똑같이 고칠 수 있습니다.
- 비밀번호는 서버에 암호화(bcrypt)되어 저장되고, 관리자도 볼 수 없습니다.
- 비밀번호를 10번 틀리면 그 아이디는 10분 동안 잠깁니다.
- **비밀번호를 잊은 사람**이 있으면: 관리자 모드에서 **내 정보 → 다른 사람 비밀번호 새로 정해 주기**에 그 사람의 아이디와 새 비밀번호를 넣고, 그 비밀번호를 알려 주세요.
- 본인 비밀번호는 **내 정보 → 비밀번호 바꾸기**에서 바꿉니다. 바꾸면 다른 기기는 자동으로 로그아웃됩니다.

**참여 코드**
- 회원가입할 때만 필요합니다. 이미 가입한 사람은 코드를 몰라도 됩니다.
- 녹음 파일 업로드는 기술적으로 로그인과 별개로 열려 있어서, 사이트 밖에서 파일만 올려 두는 것은 완전히 막지 못했습니다. 대본·세트는 로그인해야만 올릴 수 있습니다. 걱정되면 Supabase **Storage → audio**에서 가끔 확인하세요.

**Supabase 무료 플랜**
- 데이터베이스 500MB, 파일 저장 1GB(m4a 녹음 기준 수백 개), 월 데이터 전송 5GB.
- **일주일 동안 이용이 거의 없으면 프로젝트가 일시정지**됩니다. 일주일 전에 경고 메일이 오고, Supabase 대시보드에 들어가 **Resume**을 누르면 다시 켜집니다 (데이터는 그대로).
- 무료 플랜은 자동 백업이 없습니다. 사이트의 **백업(녹음 포함)**을 가끔 내려받아 보관하세요.

**영구 삭제한 세트의 녹음 파일**
- 영구 삭제해도 녹음 파일은 Storage에 남습니다(누구도 지울 권한이 없게 해 두었기 때문). 용량이 신경 쓰이면 Supabase **Storage → audio**에서 직접 지우세요.

**문제가 생기면**
- 사이트 위쪽에 “서버에 연결하지 못해…” 문구가 보이면: 3단계의 URL·키가 정확한지, Supabase 프로젝트가 일시정지 상태가 아닌지 확인하세요.
- “참여 코드가 맞지 않아요”: 2단계에서 정한 코드와 같은지 확인하세요 (대소문자 구분).
